# My Voice AAC — English Only

A picture-to-speech AAC communication web application for English-speaking children. Includes AAC communication, separate optional English learning activities, routines, and teacher/parent settings.

## Open the app
https://supaksiri.github.io/my-voice-aac/

If the site is not published, enable **Settings > Pages > Deploy from a branch > main / (root)** in GitHub.

## V2 features
- Quick Speak communication shortcuts: Help, Stop, No, Break, Pain
- Predictably ordered **Core Words** board for building communication
- Device-based English text-to-speech with available US / UK / Australia settings
- Optional English-learning practice, kept separate from AAC
- Custom photo cards, routines, browser-local profiles and exports
- Web app manifest and offline caching after a successful initial online visit

## Limitations and safeguarding
This is a pilot, not a professional AAC assessment. Emoji are placeholders, not standardized AAC symbols. Test voice support on the target device: **offline voices depend on the operating system/browser and cannot be guaranteed**. Browser storage is device-local and may be erased. Do not place child photos or personal data in this public GitHub repository. The Teacher/Parent arithmetic gate is not true authentication. Consult AAC users and a speech-language professional to individualize vocabulary, access, and communication goals.

## Backup
Export JSON from Teacher/Parent before updating devices or clearing browser storage.
