# Starter AAC Illustration Pack — 50 English Cards

## Visual style (reuse for every image)

> A clearly recognizable, high-quality 2D semi-realistic cartoon illustration for an English-language AAC communication board. Friendly rounded shapes, warm but not overstimulating colors, soft flat shading, accurate object proportions, clean light plain backdrop, strong visual hierarchy, centered large subject, minimal details and no irrelevant objects. Accessible, culturally inclusive character design; consistent drawing style and scale across all cards. One square 1:1 composition; no text, no letterforms, no logo, no watermark. Illustration is designed for picture communication rather than decoration.

For **abstract core vocabulary**, picture interpretations are *candidates*, not universally understood symbols. Trial each with AAC users and speech-language professionals; offer alternatives or real-photo customization. Avoid relying on identical gestures meaning the same thing in every culture.

**Output:** create a separate square image for every row; export WebP (ideally 512×512) under the exact path. Do not create one sprite sheet. 

**Important:** do not place identifiable children's photographs or private records in this public GitHub repository. Use non-identifiable illustrations only.

## Adding an illustration

1. Generate and inspect one image.
2. Export to the named WebP path.
3. Upload the WebP to the matching `assets/cards/...` path using **Add file → Upload files**.
4. Reload the live app. Missing assets fall back to the original pictogram automatically.
5. Test comprehension with intended AAC users. Keep the chosen symbol stable once adopted.

The code's image paths live in `cards.js`. Users' custom photo cards can still override default imagery on their own device.
